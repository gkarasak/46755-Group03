## How to Run

### 1. Set the hour
Open `main.py` and change line 6:
```python
HOUR = 18   # change this to any hour from 1 to 24
```
This is the only place you need to set the hour — all steps will automatically use it.

### 2. Run all steps
Open a terminal in the project root and run:
```bash
python main.py
```

All results and plots are saved to the `Results/` folder automatically.

## What Each Step Does

| Step | File | Description |
|------|------|-------------|
| 1 | `Assignment_1_step_1.ipynb` | Day-ahead copperplate market. Clears energy market for the selected hour, computes clearing price, producer surplus, consumer surplus and social welfare. Saves results to `Results/DA_results_step1.json`. |
| 2 | `Assignment_1_step_2.py` | Adds a battery storage unit to the 24-hour market. Runs sensitivity analysis on storage capacity and power limits. |
| 3 | `Assignment_1_step_3_nodal.ipynb` | Nodal pricing with DC power flow and transmission constraints. |
| 3 | `Assignment_1_step_3_zonal.ipynb` | Zonal pricing — aggregates nodes into zones and clears the zonal market. |
| 5 | `Assignment_1_step_5.ipynb` | Balancing market after a generator outage and wind forecast errors. Computes balancing price and compares one-price vs two-price settlement schemes. |
| 6 | `Assignment_1_step_6.ipynb` | Reserve market (European sequential) and joint energy+reserve market (US style). Compares clearing prices, dispatch and welfare across both approaches. |

## Notes
